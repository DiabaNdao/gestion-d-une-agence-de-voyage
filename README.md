#  Gestion d’une agence de voyage

# Description

Projet de base de données réalisé dans le cadre du cours **Base de données I (SMI1001)** à l’UQTR.

L’objectif du projet est de concevoir une base de données permettant de gérer les **clients, réservations, paiements, voyages, circuits, membres, rabais et accompagnateurs**.

# Contenu du projet

* Diagramme Entité-Relation
* Conception des tables
* Requêtes SQL avec Oracle
* Triggers pour contrôler les données et les réservations
* Rapport du projet

# Technologies

* Oracle SQL
* SQL

# Principales fonctionnalités

* Gestion des réservations
* Gestion des paiements
* Gestion des membres et des rabais
* Gestion des voyages et des circuits
* Vérification de la disponibilité des accompagnateurs
* Contrôle du nombre maximal de participants
* Validation des données des clients
